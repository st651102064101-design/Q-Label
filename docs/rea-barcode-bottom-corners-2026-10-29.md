Root cause in Q LABEL: both SVG and canvas clipped to the entire object bounds, which include the human-readable text. Thus the lower clip corners appeared below the bars. Implementation in gui/preview.js calculates the actual bar height for linear and catalog barcodes, limits radius against bar dimensions and adds a rectangular region below the bars for HRI. Ordinary images keep their full-height rounded clip. Both SVG editor/export and direct canvas raster use the same height and clipping geometry.
